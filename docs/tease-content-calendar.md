# Underdog City — Pre-Launch Tease Content Calendar

Goal: build the email list + followers before **Throne at the Bottom (July 31)**.
Every post drives to **theunderdogcity.com** (swap to the smart link on launch day).
All free: the **mask**, the **cover**, **song hooks**, and **CapCut**.

## The workflow (read once)
- **Make it once, post everywhere.** Build one vertical **9:16** clip → post as a
  YouTube Short + TikTok + Facebook Reel (+ IG/X when added). One asset, 3–4 posts.
- **Hook in the first 2 seconds** — a visual or sonic grab before anyone can scroll.
- **Keep music clips under 60 seconds** (YouTube Content ID self-block rule).
- **Export clean from CapCut — no TikTok watermark** (YouTube suppresses watermarked clips).
- **Toggle "AI-generated content"** when the platform asks (TikTok/Meta/YT require it for AI visuals).
- **Every caption ends with a CTA** to the site. Pin a comment with the link too.
- Default CapCut recipe: import image → keyframe a slow zoom → add text → drop an
  atmospheric/riff audio bed → export 9:16, 1080p, clean.
